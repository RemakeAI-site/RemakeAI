# REMAKE AI STUDIO

**Content Management System** для канала [@remake.ai.by](https://www.tiktok.com/@remake.ai.by). Рубрики, публикации, оригинальные медиафайлы, идеи и календарь доступны из одного интерфейса.

## Быстрый запуск

Установите актуальный [Node.js LTS](https://nodejs.org/) и распакуйте проект. В терминале откройте папку с `package.json`.

```bash
npm ci
npm run dev
```

Откройте локальный адрес из терминала. При первом запуске создаются 11 стартовых рубрик. Библиотека публикаций и идей начинается с нуля. Wrangler хранит локальные данные D1 и R2 на диске.

## Доступ

Авторизации и аккаунтов в студии нет. Любой посетитель адреса приложения получает доступ к чтению и изменению материалов. Корзина, ограничения и резервные копии помогают при ошибках, но не обеспечивают конфиденциальность. Перед переносом реальных материалов на доступный из интернета адрес подготовьте независимую резервную копию.
