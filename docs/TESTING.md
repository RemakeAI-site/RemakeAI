# Проверка REMAKE AI STUDIO

## Локальные команды

Запускайте команды из папки проекта после `npm ci`.

```bash
npm run lint
npm run typecheck
npm run build
npm test
npm run test:integration
npx playwright install chromium
npm run test:e2e
```

Сценарии запускают отдельные локальные D1 и R2. На Linux Playwright использует системный Chromium по пути `/usr/bin/chromium`, если он установлен. Для визуальной отладки сначала запустите отдельную студию на порту 8787, затем выполните `npx playwright test --headed` в другом терминале. Используйте отдельный каталог состояния, так как тесты создают записи.

## Матрица приёмки

| Сценарий | Проверка |
| --- | --- |
| Чистый запуск | 11 рубрик с нужными названиями, ноль публикаций и идей |
| Рубрики | Создание, переименование, обложка, вложенность, перенос, запрет циклов |
| Публикации | Редактирование и сохранность после перезапуска, статусы, поиск и фильтры |
| Оригиналы | Пять изображений, изменение порядка, скачивание и совпадение SHA-256 |
| Видео | Воспроизведение и Range, скачивание, сохранение метаданных после перезапуска |
| Порог готовности | 0 → красный, 1–2 → жёлтый, 3 → зелёный, опубликованный выпуск исключается из готовых |
| Идеи | Создание, референсы, преобразование и связь с публикацией |
| Корзина | Удаление, восстановление, сохранность описания и файлов |
| Два окна | Независимые браузерные сессии получают изменения обоих направлений |
| Адаптивность | 320, 360, 390, 430, 768, 1024, 1280, 1440 и 1920 px |
| Большая библиотека | Несколько страниц данных, поиск, фильтры и статистика |
| Сбои | Нет сети, прерванная загрузка, неподдерживаемый тип, предел размера, недоступность D1 и конфликт версий |
| Копии | Экспорт и восстановление в чистом окружении с проверкой связей и хешей |

## Исправления во время проверки

Локальная D1 отклоняла начальный запрос и системные выборки с шестью или более частями объединённого запроса. Запросы переработаны под ограничения D1. Повторный прогон подтвердил стартовое наполнение, список корзины и диагностику.
