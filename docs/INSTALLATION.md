# Локальная установка

## Что понадобится

- [Node.js](https://nodejs.org/) 22.13 или новее с npm. Подойдёт Node.js 24 LTS.
- Терминал. В Windows подойдут PowerShell или Windows Terminal, в macOS и Linux подойдет штатное приложение терминала.
- Доступ к npm для первой установки зависимостей и место на диске под зависимости, тесты и оригиналы.
- Актуальный Chrome, Edge, Firefox или Safari.

## Первый запуск

1. Распакуйте ZIP. Откройте в терминале папку `remake-ai-studio`, где находится `package.json`.

2. Проверьте, что установщик добавил Node.js и npm в PATH.

   ```bash
   node --version
   npm --version
   ```

3. Установите зависимости и запустите приложение.

   ```bash
   npm ci
   npm run dev
   ```

4. Откройте [http://127.0.0.1:8787](http://127.0.0.1:8787) или адрес, который напечатал Wrangler. Оставьте терминал открытым на время работы. Для остановки нажмите Ctrl+C.

При запуске применяется схема D1 и заполняются начальные рубрики, статусы и настройки. Первый запуск чистой базы даёт 11 рубрик и нулевое количество публикаций и идей. Повторное применение начальных данных рассчитано на сохранение ваших правок.

## Команды

| Команда | Назначение |
| --- | --- |
| `npm run dev` | Подготовить и запустить локальное приложение |
| `npm run db:migrate` | Применить миграции к локальной D1 |
| `npm run db:seed` | Записать стартовые данные после миграций |
| `npm run build` | Собрать статические ресурсы интерфейса в `dist/` |
| `npm run typecheck` | Проверить типы TypeScript |
| `npm run lint` | Проверить код ESLint |
| `npm test` | Запустить модульные тесты |
| `npm run test:integration` | Запустить интеграционные проверки на изолированных данных |
| `npm run test:e2e` | Запустить браузерные проверки Playwright |

Для локальных D1 и R2 не нужны аккаунт Cloudflare и облачные ключи. Для обычной работы в локальном режиме не добавляйте `--remote` к командам Wrangler. По умолчанию данные привязаны к каталогу `.wrangler/state`. Чтобы взять свободный порт и отдельный каталог для теста, используйте `npm run dev -- --port 8790 --inspector-port 9231 --persist-to .wrangler/sandbox`. Если распаковать чистую копию проекта в другую папку, она откроется со своими локальными данными. Для переноса материалов используйте [резервную копию](BACKUP.md).

Если терминал сообщает о занятом порте, завершите другой экземпляр студии или выберите свободный порт командой `npm run dev -- --port 8790 --inspector-port 9231`. При сбоях npm проверьте, что терминал открыт в папке с `package.json`, а Node.js соответствует указанной версии.

## Локальная проверка выпуска

```bash
npm run lint
npm run typecheck
npm run build
npm test
npm run test:integration
npx playwright install chromium
npm run test:e2e
```

На Linux установщик Playwright может запросить системные библиотеки. Если их нет, используйте `npx playwright install --with-deps chromium` там, где у вас есть права на установку пакетов.
