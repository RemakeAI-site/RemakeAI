# Файловое хранилище

Оригиналы лежат отдельными объектами в закрытом R2, а их метаданные — в D1. Wrangler эмулирует оба сервиса на локальном диске. В базе сохраняются имя, MIME, формат, размер и SHA-256, а при наличии также размеры кадра и длительность.

## Загрузка и целостность

1. Перед началом сервер проверяет тип, объявленный размер, существование карточки и остаток места. Если превышен один из лимитов, API отклоняет запрос.
2. Загрузка идёт через Worker частями по 8 MiB. Последняя часть может быть меньше. Размер отдельного оригинала ограничен 100 MiB для изображения и 4 GiB для видео. Клиент показывает прогресс и повторяет прерванную часть при временной сетевой ошибке. Если закрыть страницу или исчерпать попытки, выберите файл для новой загрузки. Для отмены сессии используется отдельная серверная операция. В облаке ежедневная задача обрабатывает незавершённые сессии без изменений от 24 часов. Для проверки этой задачи локально вызовите `curl http://127.0.0.1:8787/cdn-cgi/local/scheduled`, пока работает локальный сервер. В R2 также действует правило обслуживания незавершённых multipart-загрузок.
3. Сервер проверяет подпись файла и сверяет контрольную сумму собранного оригинала. После завершения создаются метаданные и нужная связь с публикацией, идеей, рубрикой или логотипом.
4. R2 хранит оригинальные байты. Превью создаётся отдельным объектом, когда поддерживается декодирование. Скачивание оригинала работает независимо от наличия превью.

Сервер принимает PNG, JPEG, WebP, GIF, AVIF, HEIC/HEIF, MP4, MOV и WebM. Просмотр и извлечение длительности видео зависят от кодеков браузера. Если доступен поддерживаемый оригинал без экранного превью, его можно скачать. Range-запросы поддерживают получение отдельных фрагментов видеопотока и перемотку.

Сравнить оригинал и скачанный файл можно в терминале. Значения SHA-256 должны совпасть. Имя скачанного файла может отличаться.

```bash
sha256sum original.png downloaded.png
# В macOS
shasum -a 256 original.png downloaded.png
```

В Windows PowerShell используйте `Get-FileHash original.png, downloaded.png -Algorithm SHA256`.

## Замена, скачивание и удаление

Замена создаёт новый объект и оставляет предыдущую связь доступной для восстановления. Изменение порядка меняет связи и не перезаписывает оригиналы. При тиражировании публикаций и переносе материалов идеи один объект может использоваться несколькими карточками.

Наборы до 256 MiB и до 40 файлов выдаются ZIP-архивом. Для заведомо больших наборов интерфейс выдаёт отдельные ссылки, чтобы скачивать файлы партиями. Параметр скачивания только фотографий исключает видео.

Используемое пространство включает оригиналы и отдельные превью, в том числе файлы, ожидающие окончательной очистки. Значения раздела «Система» вычисляются из данных приложения и помогают выявить крупные публикации и рубрики. Фактический счёт и незавершённые объекты провайдера проверяются в панели Cloudflare.

## Квота

Стартовая квота приложения — 10 GiB, предупреждение — 8 GiB. Эффективный потолок определяется также переменной Worker `MAX_STORAGE_BYTES`. Для роста библиотеки сначала проверьте план провайдера, затем измените серверный потолок и настройки студии. База хранит метаданные отдельно, поэтому увеличение медиаобъёма не требует увеличения размера базы на такой же объём.

Workers Free ограничивает CPU HTTP-запроса 10 мс, а R2 устанавливает требования к размерам multipart-частей. Повторите проверку загрузки, перемотки и пакетного скачивания на выбранном тарифе с файлами реального размера перед переносом большой библиотеки.

[R2 multipart](https://developers.cloudflare.com/r2/api/workers/workers-multipart-usage/) · [Workers limits](https://developers.cloudflare.com/workers/platform/limits/)

## Перенос к другому поставщику

1. Прекратите изменения и сделайте полную копию.
2. Подготовьте закрытое хранилище назначения. Сохраните соответствие между ID медиа и ключом объекта.
3. Перенесите объекты поэтапно. Не синхронизируйте удаления во время первой миграции.
4. Подключите серверный адаптер с поддержкой чтения, Range, записи, multipart, проверки состояния и удаления. Храните учётные данные только на сервере.
5. Сравните объёмы и SHA-256, проверьте превью, видео, корзину и восстановление. Оставьте исходное хранилище доступным для отката до проверки.

[R2 S3 compatibility](https://developers.cloudflare.com/r2/api/s3/api/) · [Копирование через rclone](https://developers.cloudflare.com/r2/examples/rclone/)
