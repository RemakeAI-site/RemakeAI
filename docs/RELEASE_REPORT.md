# REMAKE AI STUDIO 1.0.0

## Что входит в выпуск

| Раздел | Возможности |
| --- | --- |
| Главная и рубрики | 11 стартовых рубрик, живые счётчики, поиск, обложки и произвольная вложенность |
| Публикации | Карточки, статусы, фильтры, доска, массовые действия, пользовательские поля, копирование TikTok-текста |
| Медиа | Приватное объектное хранилище, побайтовая передача оригиналов, SHA-256, multipart, Range, отдельно сохраняемые превью и ZIP |
| Идеи | Референсы, файлы, закрепление, дублирование и преобразование в публикацию |
| Календарь, архив, корзина | Расписание по часовому поясу, перенос, рекомендации по архиву, подтверждение очистки и восстановление |
| Система | Диагностика D1/R2, расход места, настройки квот, история, резервные копии через браузер и CLI |
| Совместная работа | Обновление активных вкладок примерно раз в пять секунд и проверка версий при сохранении |
| Интерфейс | Адаптивные страницы, фирменный логотип и установка через PWA в поддерживаемых браузерах |

## До будущего подключения облака

- Создать новый репозиторий и подключить Worker, D1 и закрытый R2 после отдельного решения о публикации. В [DEPLOYMENT.md](DEPLOYMENT.md) описаны настройка, будущие обновления и проверка адреса из Беларуси на домашнем и мобильном интернете.
- Измерить работу на реальных iPhone и Android с выбранным тарифом и типичными для проекта оригиналами. Поддержка отображения HEIC/HEIF и некоторых видеокодеков зависит от браузера.
- Настроить отдельное место хранения резервных копий и расписание в соответствии с [BACKUP.md](BACKUP.md). Восстановление выполняется в чистую студию. Браузерный ZIP ограничен 64 МиБ и 38 объектами для экспорта. Для большего объёма доступен CLI.
- После публикации любой, кто откроет сайт, сможет читать, изменять и удалять материалы. Корзина, квоты и ограничения частоты снижают риск случайных потерь и расхода ресурсов. Поэтому резервную копию следует хранить отдельно от рабочего R2.
- Проверить стоимость Workers, запросов и места в R2. При постоянном хранении 100 ГБ в R2 Standard ориентир составляет около 1,35 USD в месяц за место после стандартной бесплатной квоты, а при 500 ГБ — около 7,35 USD. Отдельно учитываются оплачиваемые операции, возможный план Workers, налоги и вторичное хранилище. [Тарифы R2](https://developers.cloudflare.com/r2/pricing/)
- При смене поставщика хранилища потребуется новый серверный адаптер: текущий интерфейс хранения отделён от React, а реализация использует R2. Для миграции предусмотрен переносимый комплект манифеста и объектов.

В ходе подготовки GitHub и Cloudflare не использовались для публикации. Медиа канала можно импортировать в студию после запуска.
